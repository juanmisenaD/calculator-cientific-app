# Calculadora Científica App

Aplicación web de calculadora científica liviana y autónoma, desarrollada con HTML5, CSS3 y JavaScript puro (vanilla). Funciona localmente en el navegador sin necesidad de servidores o dependencias externas.

---

## Estructura del proyecto

```text
calculadora-cientific-app/
├── index.html    # Estructura e interfaz de usuario de la calculadora
├── styles.css    # Estilos visuales en modo oscuro y maquetación responsive
└── main.js       # Lógica matemática, control de pantalla y formateo con RegEx
